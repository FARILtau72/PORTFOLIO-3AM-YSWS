## Cara Penggunaan

### 1. Mengakses Website (Pengunjung)
1. Buka tautan [https://fariltau72.github.io/PORTFOLIO-3AM-YSWS/](https://fariltau72.github.io/PORTFOLIO-3AM-YSWS/) di browser.
2. Gunakan menu navigasi di bagian atas untuk berpindah antarbagian halaman atau membuka halaman **Blog**.
3. Lihat bagian **Contact** di bagian bawah untuk menghubungi pemilik portofolio.

### 2. Menjalankan & Mengedit Secara Lokal (Developer)
1. **Clone repositori:**
   ```bash
   git clone [https://github.com/fariltau72/PORTFOLIO-3AM-YSWS.git](https://github.com/fariltau72/PORTFOLIO-3AM-YSWS.git)


2. **Masuk ke direktori proyek:**
```bash
cd PORTFOLIO-3AM-YSWS

```


3. **Edit konten sesuai kebutuhan:**
* Ubah konten utama di `index.html`.
* Ubah artikel blog di `blog.html`.
* Sesuaikan tampilan dan gaya pada file CSS terkait.


4. **Jalankan di browser:** Buka file `index.html` secara langsung di browser atau gunakan ekstensi **Live Server** di VS Code.

### 3. Publikasi Perubahan ke GitHub Pages

```bash
git add .
git commit -m "Update portfolio content"
git push origin main

```

Tunggu beberapa saat hingga GitHub Pages memperbarui tampilan di [https://fariltau72.github.io/PORTFOLIO-3AM-YSWS/](https://fariltau72.github.io/PORTFOLIO-3AM-YSWS/).
